# 万物审判庭

**v1.3.0 · 持续迭代中**

一个认真审判生活破事的互动娱乐法庭。周一、闹钟、已读不回、老板说“简单改一下”……只要让你觉得离谱，就可以来本庭走一遍正式流程。

## 已实现
- 案件大厅：6 个主题分类、16 个常驻被告与自定义起诉
- 三步立案：选择被告、提交罪名、呈上证据
- 法官风格、判决书、本地卷宗与 1080×1440 分享海报
- 图鉴：案件被告、法庭角色、16 件法庭物件及场景陈列
- 52 张本地生成图片按类别接入页面，无远程素材依赖

## 视觉方向
复古手绘木刻版画、旧羊皮纸、深咖啡墨线、朱砂红与少量赭金。图片只承担场景、角色、物件和装饰；真实文字与交互由 HTML/CSS/Canvas 实现。禁止金属 3D、手游 UI 和霓虹渐变。

设计规范：`docs/DESIGN_SYSTEM.md`
产品路线：`docs/ROADMAP.md`

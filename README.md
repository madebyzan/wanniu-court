# 万物审判庭

**v1.2.0** · 一个认真审判生活破事的娱乐型互动法庭。

- 6 个案件分类、36 个常驻被告、自定义立案
- 分步选择罪名、证据、法官风格，生成荒诞判决
- 1080×1440 高清判决海报、历史卷宗与小红书分享适配
- 原创版画视觉系统：白鸽法官、猫律师、青蛙书记员、分类插画、法庭物件
- 本地优先、无后端、无远程资源依赖

## 本地开发

```bash
npm install
npm run dev
```

## 质量验证与小红书打包

```bash
npm run check
npm run package:xhs
```

技术架构、视觉规范、内容规范与平台适配说明见 `docs/`。

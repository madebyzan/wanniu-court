# 万物审判庭

**v1.4.0 · 产品体验打磨版**

把日常里的小烦恼，送进一间认真得有点荒唐的复古法庭。

## 核心体验
- 16 位常驻被告与自定义立案；不同被告提供专属罪名和证据线索
- 三步正式立案：选择被告、确定指控、提交 1–2 条证据
- 每日专属案件按本地日期轮换；随机速审可以快速生成判决
- 三种审判官风格，按案件类别生成不同判罚和法官点评
- 再审保留原被告、罪名和证据；判决后可以反馈“刚好/太轻/太重”
- 卷宗在本地保存；可逐条查看、删除和再次审判
- 3:4 判决海报预览、长按保存、下载、系统分享与小红书文案复制

## 视觉方向
复古手绘木刻版画、羊皮纸、深咖啡墨线、朱砂红与少量赭金。52 张场景、角色、被告、物件和装饰图片全部接入实际页面；真实文字和交互由 HTML/CSS/Canvas 渲染。

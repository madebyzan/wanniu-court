# 万物审判庭

**v1.2.0 · 持续迭代中**

一个认真审判生活破事的互动娱乐法庭。周一、闹钟、已读不回、老板说“简单改一下”……只要让你觉得离谱，就可以来本庭走一遍正式流程。

## 已实现

- 案件大厅：6 个主题分类，常驻被告目录与自定义起诉
- 三步立案：选择被告、提交罪名、呈上证据
- 法官风格：不同审判风格生成不同判决口吻
- 判决结果：案号、罪名、证据、判罚、执行要求与法官点评
- 分享：1080×1440（3:4）Canvas 判决海报、复制分享文案
- 卷宗：本地保存、查看、删除历史判决
- 本地优先：无需注册，不依赖业务后端，不加载远程图片、字体或脚本

## 运行

Node.js 20+，无第三方运行时依赖：

```bash
npm run dev
```

打开 http://127.0.0.1:4173。

## 质量检查

```bash
npm run check
npm test
```

GitHub Actions 会对 main 的每次 push 和 pull request 执行检查。

## 设计方向

旧纸白、炭墨黑、朱砂红与赭金；复古版画、法庭印刷物、编辑式中文排版。真实 UI 文字由 HTML/CSS/Canvas 渲染，生成图只承担插画角色，不把 AI 伪文字放进界面。

设计标准：`docs/DESIGN_SYSTEM.md`
开发规范：`docs/CONTRIBUTING.md`
产品路线：`docs/ROADMAP.md`

## 迭代原则

不等全部做完才推送。每一轮有价值的 UI、插画、交互和质量改进都会直接提交到 `main`；小红书真实客户端尚未验收的能力会明确标记为待验收。

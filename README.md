# 万物审判庭

一个认真审判生活破事的互动娱乐法庭。

> 周一、闹钟、已读不回、老板说“简单改一下”……只要让你觉得离谱，就可以来本庭走一遍正式流程。

## 产品体验

- 案件大厅：按生活、职场、人际、数字世界、自我管理和校园分类浏览被告
- 立案流程：选择被告、提交罪名、选择证据、指定法官风格
- 判决结果：生成带案号、证据、判罚和法官点评的娱乐判决书
- 分享：生成适合小红书的 3:4 高清图片，并提供笔记文案
- 我的卷宗：本地保存、查看和删除历史案件
- 本地优先：不要求注册，不依赖业务后端

## 视觉方向

旧纸白、炭墨黑、朱砂红与赭金；复古版画插画、印刷纸感、清晰的中文编辑式排版。避免通用 SaaS 渐变、过度圆角卡片和 AI 风格装饰。

## 当前状态

持续开发中。界面、插画资产和交互会按小版本逐步提交到 `main`，不会等待所有功能完成才推送。

完整本地开发包会随迭代同步更新。

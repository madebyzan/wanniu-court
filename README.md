# 万物审判庭

**v1.5.0 · 完整产品版**

把日常里的小烦恼，送进一间认真得有点荒唐的复古法庭。选一个被告，提交指控，等法官给你一个交代。

## 核心体验

- **16 位常驻被告 + 自定义被告**：每位被告都有专属罪名、专属证据和专属争议焦点，不是通用句库随机拼接
- **三步正式立案**：选择被告 → 确定指控与审判官 → 呈上证据；每一步只有一个核心决定
- **两种判决结果**：两条证据或铁面审判官 → 有罪实刑；单一证据配温和审判官 → 责令和解。卷宗可按 全部 / 有罪 / 和解 筛选
- **每日专属案件**：按本地日历日期固定轮换，今日审过会标记，明日换人
- **随机速审**：把今天交给命运，一键出判决
- **再审**：保留原被告、罪名与证据，判决书标明审级
- **判决反馈**：判得刚好 / 太轻 / 太重，态度写进本地卷宗
- **分享物料**：1080×1440 判决海报（Canvas 现绘，文字不烘焙进底图）、长按保存、下载原图、系统分享、小红书文案复制
- **本地卷宗**：删除前二次确认，只存本机，不上传、不联网、不读取任何账号

## 视觉

复古手绘木刻版画 + 羊皮纸 + 深咖啡墨线 + 朱砂红与赭金。

52 张场景、角色、被告、物件与装饰素材全部接入真实界面，并且各自只承担自己擅长的角色：

- 场景图进入内容窗口，用 `object-fit: cover` 裁切，永不拉伸
- 角色与物件是透明立绘，用 `contain` 完整呈现
- `verdict-paper.png` 判决书纸按像素验证过的空白区切成九宫格边框，纹章与蜡封保持原始比例，只有中间的空白纸面随内容伸缩
- `page-corners.png` 的四枚角花按四角平铺，不再整张铺满页面
- 按钮、标签、丝带用装饰 PNG 的原始比例呈现

界面文字、按钮状态、卡片、印章、分隔线全部由 HTML/CSS/SVG 渲染，因此在任何分辨率下都是清晰的。

## 开发

Node.js 20+，产品运行时零第三方依赖。

```bash
npm run dev      # http://127.0.0.1:4173
npm run check    # 校验 52 张素材存在且已接入界面
npm test         # 21 项产品与视觉契约测试
```

需要跑端到端校验和截图复核时，见 [tools/README.md](tools/README.md)：

```bash
node tools/verify.mjs   # 46 项端到端断言
node tools/tour.mjs     # 全界面截图
```

## 说明

- 娱乐法庭，不具法律效力，不构成法律意见
- 判决只回应你提交的案件类别、争议焦点和所选审判官风格
- 所有数据保存在浏览器 localStorage，删除即消失

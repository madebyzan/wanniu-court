# 开发与提交规范

## 环境

- Node.js 20+
- 不需要第三方运行时依赖
- 不使用远程图片、字体、脚本或 API

## 本地运行

```bash
npm run dev
```

默认地址为 `http://127.0.0.1:4173`。

## 质量检查

```bash
npm run check
npm test
```

提交前必须保证两个命令通过。测试会检查内联脚本语法、移动端 viewport、远程资源约束、关键交互入口和本地历史边界。

## 代码约束

- 领域逻辑必须保持纯函数，随机源和当前时间要能注入
- DOM 事件统一使用委托，避免重复绑定
- 所有用户输入进入 HTML 前必须转义
- 历史数据必须做结构校验、去重并设置上限
- 平台能力必须 feature-detect，浏览器预览要有降级路径
- 分享海报只使用 Canvas 本地渲染
- 不引入不必要的依赖，不复制已有业务规则

## 视觉约束

参见 [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)。新插画要服务具体场景，不用 AI 生成图里的文字冒充真实 UI。

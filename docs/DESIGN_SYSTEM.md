# 万物审判庭视觉系统

## 核心定位
这不是效率 SaaS，也不是宫廷 RPG。它是一份认真制作的荒诞法庭刊物：把日常小情绪、小麻烦和离谱行为，变成值得保存与分享的正式判决。

## 插画语言
- 复古手绘木刻版画，像老童话书、讽刺漫画和旧报刊插图。
- 深咖啡色粗墨线，粗细不均；套色可有轻微错位。
- 填色保留颗粒、网点、交叉排线、纸张纤维和磨损痕迹。
- 角色比例简洁、表情夸张、有喜剧动作；避免光滑 3D、矢量图标感和手游质感。
- 场景插画可以丰富；独立角色/物件必须主体完整、轮廓清晰。

## 色彩
- 旧羊皮纸：#ead9b9 / #f6ebd4
- 炭墨/深咖啡：#30251e / #39251d
- 朱砂红：#a43c2d / #7d2b24
- 赭金：#b18a4e，仅用于细节与编号
- 暗橄榄绿：#68704d，少量点缀
- 禁止金属镜面高光、霓虹渐变和发光 UI。

## 排版与布局
- 中文标题优先宋体/衬线字体，正文使用系统黑体。
- 使用留白、细线、编号、印章和纸张层级建立秩序。
- 案件大厅像旧档案目录；立案像填写纸质诉状；判决书像独立印刷品。
- 桌面端使用刊物式宽版布局，移动端自然重排，不把桌面网页缩成窄手机壳。
- 场景图负责营造故事；不可把 AI 场景图当 UI。真实文字、表单和交互必须由 HTML/CSS/Canvas 渲染。

## 52 张素材的使用规则
- scenes：主审判庭用于首页；案件大厅用于立案入口；立案大厅用于首页受理说明；秘密合议室用于审议页；档案室用于卷宗页与场景图鉴；判决纸用于判决页面背景。
- characters：六个角色全部出现在首页角色席、立案/审议状态和角色图鉴。
- defendants：16 个案件卡片一一绑定自己的独立插画，不以字母占位替代。
- props：16 件法庭物件逐件展示在“法庭物件”图鉴页，并在首页和流程中复用关键物件。
- decor：8 张装饰图用于按钮、案件卡框、分类标签、章节横幅、分隔线、页面四角与合议横幅。
- 所有生成图只做插画/装饰，不烘焙真实 UI 文案；不通过代码对图中主体进行二次裁切。

## 交互与质量
- 每一步突出一个主要决定；选中、焦点、禁用、空态、错误态明确。
- 动画只做短暂反馈，支持 prefers-reduced-motion。
- 用户自定义文本必须转义。
- 判决分享图固定 1080×1440（3:4），案号、被告、罪名、证据、判罚、审判官和娱乐免责声明由 Canvas 绘制。

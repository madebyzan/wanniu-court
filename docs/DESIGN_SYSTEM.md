# 视觉系统

## 设计意图

万物审判庭不是效率 SaaS。它是一份认真制作的荒诞法庭刊物：用户来这里不是为了“提升效率”，而是为了把日常的小情绪变成值得分享的判决。

## 视觉基调

- 旧纸白：页面底色与判决纸张
- 炭墨黑：主标题、深色主视觉
- 朱砂红：行动、判决、印章
- 赭金：小标题、编号和辅助标记
- 版画式插画：角色、法庭和生活物件；避免用 emoji 充当主要插画

## 排版规则

- 中文标题优先使用系统宋体/衬线字体，正文使用系统黑体
- 用字重、留白、细线和编号建立层级，不用渐变光效制造层级
- 案件卡片采用清晰的列表/目录语法，不把所有内容塞进圆角卡片
- 判决书必须像一份可保存、可分享的独立印刷品

## 交互原则

- 每一步只突出一个主要决定
- 当前选择必须有稳定的视觉反馈和键盘焦点状态
- 无数据、加载、错误和完成状态都要有明确文案
- 动画只用于反馈，不承担信息表达；尊重减少动态效果设置
- 所有用户自定义内容必须经过转义后再渲染

## 分享素材

- 判决图固定为 3:4，目标尺寸 1080 × 1440
- 保留案号、被告、罪名、主要证据、判罚、审判官与娱乐免责声明
- 海报上的文字必须由 Canvas/真实 UI 渲染，不得使用生成图片里的伪文字

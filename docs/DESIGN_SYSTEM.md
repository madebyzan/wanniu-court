# 万物审判庭 · 产品与视觉规范

v1.5.0。这份规范里每一条“禁止”都对应一次真实的翻车，改之前先读完。

## 1. 产品定位

把生活中不方便认真计较的小烦恼，包装成一场轻松、荒诞、可以分享的互动审判。

核心不是一句搞笑文案，而是一条完整闭环：

> 发现案件 → 选择被告 → 确定指控与审判官 → 呈上证据 → 合议庭评议 → 收到判决 → 表态 → 分享或再审 → 归档卷宗

判断一个功能是否该做，只看它有没有让这条链更顺、更可信。

## 2. 设计语言

- 复古手绘木刻版画：深咖啡粗墨线、颗粒、网点、纸纤维、旧印刷磨损。
- 色板固定为羊皮纸、炭墨、朱砂红、赭金。**禁止**金属 3D、霓虹渐变、玻璃拟态、手游 UI。
- 中文标题用宋体族（`Songti SC / STSong / Source Han Serif`），控件与正文用 PingFang，英文小标用 Georgia 加字距。
- 层级靠“留白 + 字号 + 一条细分隔线”表达，不靠阴影堆叠。

### 令牌

| 用途 | 值 |
| --- | --- |
| 墨 / 次级墨 / 弱墨 | `#241811` `#3d2a1e` `#6f5b46` |
| 纸 / 卡片 / 描边 | `#f2e6cf` `#f8f0dd` `#c0a377` |
| 朱砂 / 深朱砂 / 赭金 | `#99302a` `#6f1d18` `#b3873c` |

纸面颗粒是内联 SVG `feTurbulence`，不用位图，保证任意 DPI 都锐利。

## 3. 素材使用铁律

**AI 生成的装饰图是“完整构图”，不是 UI 表面。** 一旦把它 `background-size: 100% 100%` 铺到任意尺寸的容器上，纹样会变形、烘焙进去的假文字会和真实文字打架。历史版本就是这么坏的。

按素材类型选择唯一正确用法：

| 类型 | 用法 | 例子 |
| --- | --- | --- |
| 场景（横图） | `.art` 窗口 + `object-fit: cover` + 顶部/底部压暗渐变，文字绝不压在图上 | 首页 hero、立案横幅、合议室 |
| 角色 / 物件（透明立绘） | `object-fit: contain` + 羊皮纸底 | 图鉴、合议人员、空状态 |
| 完整证书纸（verdict-paper） | **按等比裁切的两条带**：纹章带 + 蜡封带 | 判决书 |
| 四角角花（page-corners） | 四条背景层，`background-size: 26% auto`，四角各一枚 | 须知、卡片内衬 |
| 按钮面 / 丝带 / 标签 | 保持原始宽高比，不铺满 | `btn-primary`、`category-label` |
| 分隔纹样（divider-ornament） | 固定高度 `object-fit: contain` | 章节分隔 |

判决书的装饰带推导（改图前先复核）：`verdict-paper.webp` 为 1086×1448，逐行扫描确认 **490–910 行是纯纸面**，纹章与流苏全部落在 0–490 行，蜡封与月桂落在 1240–1448 行。

最初把它切成四边 border-image 边框，代价是 **339px 纯装饰**（上 161 + 下 178），而且纹章带里还有约 87px 空白纸面被浪费——判决书直接滚到 2.15 屏。改成**只取上下两条等比带**：

```css
.doc-crest { aspect-ratio: 1086 / 490; }  /* 纹章带，含流苏 */
.doc-seal  { aspect-ratio: 1086 / 208; }  /* 蜡封带 */
.doc-body  { margin-top: -18.4%; }        /* 标题拉进纹章带自带的空白纸面 */
```

`aspect-ratio` 让两条带在 320/375/390/430/520/760px 下都精确等于 `宽 × 490/1086`，`object-fit: cover` 保证零变形；中间纸面是 CSS 渐变，颜色取自裁切线处的实测值（上 `#face91`、中 `#fad296`、下 `#f7cc8f`）并叠同一层颗粒，再用 30px 羽化把接缝吃掉。装饰预算从 339px 降到 231px，整页从 2.15 屏压到 1.56 屏。

`case-card-frame.webp` 的空白带太窄（1129×1393 中仅 490–900 行干净），不适合当通用卡片边框，只用于**等比呈现的空卷宗**（卷宗室空状态）。

**永远不要**用 `background-size: 100% 100%` 铺场景图或物件图。契约测试会拦住这件事。

## 3.5 小工具容器约束

产物是**离线 zip**，不是网站。以下不是建议，是容器强制：

- **页面不能联网**：无 `fetch` / `XHR` / WebSocket / SSE / 外部图片字体脚本。52 张图全部进包。
- **脚本必须是经典脚本**：`<script defer src>`，禁 `type="module"`、禁 `import`/`export`、禁顶层 await。多文件靠 `window` 命名空间与加载顺序（`platform.js` 先于 `app.js`）。
- **禁内联脚本与行内事件**：`<script>...</script>`、`onclick="..."` 会被 CSP 拦掉。样式可以内联。
- **最低基线 Chrome 61（Android 8.1 出厂 WebView）**：JS 上限 ES2017；CSS 用「61 基线层 + 能力检测增强层」，不维护两套完整样式表。
- **禁用能力**：剪贴板（`navigator.clipboard` / `execCommand`）、`a[download]` 与 blob 下载、`navigator.geolocation`、传感器、Worker、`requestFullscreen`、`window.open` / `prompt`、`eval` / `new Function` / WASM、iframe。
- **持久化只用容器 Storage**（9.46+）：`localStorage` / `IndexedDB` / Cookie / Cache API 都不许写；旧数据只允许一次性读出、写入 Storage 后清除。版本不足或接口缺失时返回 `false`，界面必须如实告知，不能假装已保存。
- **保存图片走 `writeTempFile` → `saveImageToPhotosAlbum`**；分享走平台 `share`（9.53+）；发笔记走 `postNote`；安全区优先用 `getWindowInfo`（9.49+）换算出的 `--safe-area-inset-*`。
- **复制文案改为可选中文本**：容器没有网页剪贴板，所以展示 `readonly textarea` 引导长按选中复制，并且**不设置 `-webkit-touch-callout: none`**，否则这条路也断了。
- **体积**：zip 硬上限 10 MiB，建议 ≤2 MiB。仓库里的 `assets/` 是设计原图（13 MiB），交付走 `scripts/prepare-assets.py` 按显示尺寸 ×2 DPR 重导出，最终包 1.97 MiB。

## 4. 界面骨架

移动优先，单列，`max-width: 520px` 居中，深色桌面背景衬托。

- 顶部 `app-bar`：审字徽记 + 中英文标 + 娱乐法庭声明，`position: sticky`。
- 底部 `tab-bar`：审判庭 / 立案 / 卷宗 / 图鉴，SVG 图标 + 文字，`position: fixed` + `env(safe-area-inset-bottom)`。
- 路由：`#/`、`#/trial`、`#/verdict`、`#/archive`、`#/gallery`，`popstate` 可返回。
- 内容区 `padding-bottom` 必须给 tab bar 留位。

## 5. 组件

- **按钮**：`btn--solid`（朱砂实底，全宽主操作）、`btn--plaque` / `btn--ticket`（装饰 PNG，仅用于约 3:1 的首页双入口）、`btn--ink`、`btn--ghost`、`btn--danger-solid`。必须有 `:active`、`[disabled]`、`:focus-visible`。
- **卡片**：羊皮纸渐变 + 1px 描边 + 轻投影；选中态是 2px 朱砂内描边，不是换底色。
- **粘性操作条 `pickbar`**：三步立案共用，左图右按钮，中间是当前选择。未选时给出提示而非禁用后沉默。
- **判决书 `doc`**：抬头纹章 → 标题 → 案号 → 被告 / 罪名 → 争议焦点 → 证据 → 判决牌 → 法官点评 + 印章 → 落款。
- **印章**：CSS 双环红章（界面内）与 `royal-seal.webp` 蜡封（海报内）分工不同。
- **弹层 `sheet`**：海报预览与破坏性操作确认共用，`role="dialog"` / `role="alertdialog"`，Esc 关闭，打开时锁 body 滚动。
- **空状态**：一句解释 + 一个主操作，不放假数据。
- **判决书页必须 ≤ 1.8 屏**（390px 下，当前 1.49 屏）。态度反馈压成一行 chip，操作压成一行四键。端到端测试会量这个数。
- **同屏不要出现两个长得一样的横条**。曾把「审判结束 / 案件类型 / 有罪徽章」做成一条深色圆角横条，紧贴在深色顶栏下面——用户的第一反应是组件重复了。结论：页面顶部的深色横条**只允许顶栏一条**；判决的结论、审级、案号属于文书本身，应该写进判决书抬头里（`审判结束 · 卷宗已归档` 朱砂 kicker + 标题 + 案件类型 + 案号），而不是另起一个 UI 面板。端到端测试会数折叠线以上的深色横条数量。
- **海报底部要按最坏情况预留**：判决牌钳在 `y=950` 而不是 `y=998`，因为点评两行字的末尾会落在分隔线上。canvas 排版不会自动避让，间距必须算出来。
- **canvas 中文换行必须做禁則処理**：默认按宽度硬切会把 `。` 单独甩到下一行。收尾标点（。，、；：？！）』」…—·）不许出现在行首，开首标点（「『（〈）不许留在行尾。
- **自定义被告没有立绘**：界面用首字铭牌（`.mono`，并跳过作品压暗层），海报用现绘名牌（被告 / 名称 / 自定义被告 · 本庭照单受理）。**绝不允许**拿画轴之类的装饰素材顶替被告位——那是"图片挂了"的观感。

## 6. 交互与内容规则

- 首页两个清晰入口：随机速审与正式立案；每日案件按本地日期轮换。
- 证据最多两条。达到上限时**禁用未选项并说明原因**，绝不偷偷替换用户已选内容。
- 判决结果必须回应案件类别、争议焦点和审判官风格。
- **自定义被告按用户写的词归类，不按通用句糊**。书记员对名字做关键词命中：命中最多的类别胜出，该类别里命中最多的罪名成为首条指控，焦点与证据也随类别切换。界面上直接写明「归入校园日常（命中 4 个特征词）」和「依描述命中「xxx」，本庭优先适用」——归类过程可见，不是假装认识这个人。
- **一个特征词都没命中时诚实降级**：归入自定义案件，注明「描述较少，按一般扰乱秩序处理」，绝不硬套一个类别。
- 单一证据 + 非铁面审判官 → 责令和解；两条证据或铁面审判官 → 有罪。规则固定、可解释、写进须知。
- 再审保留原被告、罪名与证据，判决书标明审级。
- 删除卷宗走应用内确认弹层。**禁止 `window.confirm`**——嵌入式 WebView 会直接拦掉。
- 搜索输入不丢焦点、不丢光标；筛选与选择不强制回到页顶。
- 不伪造联网、上传、点赞、评论或全站统计。
- **浮动层不得压住用户正在输入的控件。** 自定义被告面板展开时自带「确认被告」按钮，此时底部浮动操作条让位（不渲染），并把输入框显式 `scrollIntoView({block:'center'})`——浏览器不会可靠地把聚焦元素滚到 sticky 覆盖层之上。

## 7. 无障碍

- 触控目标 ≥ 44px，正文对比度 ≥ 4.5:1（弱墨 `#6f5b46` 对纸 `#f2e6cf` 约 5.2:1）。
- 选中态同时给出 `aria-pressed`，当前页签给出 `aria-current`。
- 所有 `img` 必须有 `alt`（纯装饰写 `alt=""`）。
- 键盘可达，`:focus-visible` 有 2px 朱砂描边。
- `prefers-reduced-motion: reduce` 下关闭全部动画与平滑滚动。

## 8. 间距刻度与图片底衬

### 间距只用 6 个值：4 / 8 / 12 / 16 / 22 / 28

| 值 | 用途 |
| --- | --- |
| 4 | 控件内部（tabs 内衬、stepper 连线） |
| 8 | 同组元素之间（chip 之间、卡片内图标与文字） |
| 12 | 相邻区块之间（搜索框 → 筛选 → 网格 → 自定义面板） |
| 16 | 页边距 `--gutter`，也是区块默认间距 |
| 22 | 章节分隔（装饰分隔线上下） |
| 28 | 大段落切换 |

**一个区块的垂直间距只由一处负责**：要么它自己的 margin，要么容器的 padding。之前「装饰分隔线压住每日值班卡 1px」就是因为两边都以为对方负责。`.screen` 自带 18px 上内边距，所以 `.stepper` 不再加下边距；`.ornament` 自带 22/18 外边距，所以它前后的块不再自己补。

### 透明立绘的底衬决定观感

被告 PNG 有约 **37% 的像素是透明的**，它们身后台什么直接露出来：

- `.art` 底衬必须是暖纸色 `#f4e8d1 → #ebdcbc`。用中性灰（曾经的 `#dcc9a6`）会衬出一整片脏灰绿。
- 压暗层 `.art--scrim` **按需启用**，只给上面真的压了白字的窗口（hero、合议室）。默认全量加 scrim 会把立绘和底衬一起压暗。
- 未选中态的勾选圈不能是半透明深色圆——落在图上就是一个灰斑。改成浅纸底 + 细描边 + `+`，选中才变朱砂勾。
- 展开指示符用「`+` 旋转成 `×`」。用「右箭头旋转 90°」会被读成下载图标。

## 9. 分享物料

- 海报固定 1080×1440（3:4），纸面、纹章牌、判决牌、蜡封、印章全部 Canvas 现绘，文字不烘焙进 AI 底图。
- 长文案用 `wrapMax` 截断加省略号，绝不与判决牌重叠。
- CSP 必须允许 `img-src blob:`，否则预览图会被拦。
- 内置浏览器先给预览并提示长按保存；支持系统分享时提供原图。
- 小红书文案由用户主动复制，不自动发布、不上传。

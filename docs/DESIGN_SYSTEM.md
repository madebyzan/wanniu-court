# 万物审判庭产品与视觉规范

## 产品定位
把生活中不方便认真计较的小烦恼，包装成一场轻松、荒诞、可以分享的互动审判。核心不是“生成一句搞笑文案”，而是一条完整路径：发现案件 → 参与立案 → 提交证据 → 等待判决 → 评价裁定 → 分享或再审 → 留存卷宗。

## 视觉语言
- 复古手绘木刻版画，深咖啡粗墨线，颗粒、网点、纸纤维和旧印刷磨损。
- 羊皮纸、炭墨、朱砂红和少量赭金；禁止金属 3D、霓虹渐变和手游 UI。
- 场景承担氛围，透明角色立绘承担人物，独立物件承担证物，装饰 PNG 作为真实 UI 表面。
- 不通过代码裁切主体；角色和物件优先 object-fit: contain。
- 中文标题采用衬线/宋体气质，正文清楚易读，保留刊物式留白与信息层级。

## 体验原则
- 首页有两个清晰入口：随机速审与正式立案；每日案件固定按本地日历日期轮换。
- 正式立案分三步，每步只要求一个核心决定；被告决定罪名与可用证据。
- 证据最多两条，达到上限时明确禁用未选选项，不偷偷替换用户已选内容。
- 判决结果回应案件类别、争议焦点和法官风格，而不是全站通用句库随机拼接。
- 再审保留原被告、罪名和证据，并在新判决标明审级。
- 判决后有轻量态度反馈，可生成 3:4 海报、长按保存、下载、系统分享或复制小红书文案。
- 卷宗本地保存，删除操作明确；不伪造联网、上传、社交互动或全站统计。
- 搜索输入不丢焦点，筛选/选择不强制回到页面顶部。
- 交互有明确禁用态、选中态、键盘焦点和触控反馈；遵守 prefers-reduced-motion。

## 52 张图片使用规范
- 6 张场景分别进入首页、立案、受理说明、合议、卷宗、判决底图。
- 6 个角色分别承担法官、律师、书记员、档案员、执法官和证人职责。
- 16 个案件被告一一对应独立立绘，并在案件图鉴使用。
- 16 件法庭物件完整陈列于物件图鉴，重点物件出现在首页、流程和海报。
- 8 张装饰图用于按钮、卡片边框、分类标签、章节横幅、分隔线、页面边角和合议横幅。

## 分享物料规范
- 判决海报为 1080×1440（3:4），文字由 Canvas 绘制，避免烘焙进 AI 底图。
- 内置浏览器先显示图片预览，提示长按保存；支持系统文件分享时提供原图分享。
- 小红书文案由用户主动复制；不自动发布、不上传用户内容。
